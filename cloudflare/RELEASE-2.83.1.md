# 2.83.1 — Preserve manually added applications

Release 2.83 incorrectly treated the `manual-<UUID>` identity generated by the actual Add a role form as a missing catalogue job. Its earlier manual regression test used only a blank identity and did not cover the real form. A new actual Worker/D1 regression reproduced the 409 rejection for a manual UUID before this fix.

The shared guard now recognises both legacy empty identities and the exact UUID form used by manual entry. Studio does not request a catalogue status for these manually supplied applications, and the server preserves their existing preparation path. Their source stays explicitly unverified; this is not a sponsorship or availability finding. Arbitrary/malformed identities remain missing, and the catalogue hold/staleness guards are unchanged.

The browser fixture now exercises the real Applications form, saving a fictional title, employer, link and advert into Studio. Its local evidence check completes, with zero catalogue requests, model requests or unexpected requests, and the existing source CV remains unchanged. The manual-source disclaimer is visible. The actual Worker/D1 regression also traverses writer and reviewer for a manual UUID using fictional model responses, with no external service, even when the catalogue table is unavailable. All held/unavailable catalogue cases and late-hold tests remain.

All **691 tests** pass on pinned Node 24.19.0, as do TypeScript/build, 18 prerenders, existing browser budgets and Worker dry run. No schema, dependency graph, model, comparison, source approval, permission or allowance changes. The successful same-day recovery and dependency checks remain applicable. The earlier 2.83 receipt remains historical and is not rewritten.

Deployment is pending at this source commit. Compatible prior fallback is **2.82 Worker `3b8e7099-3ffd-45b9-b58e-70093065567a`**, which preserves data/history but removes the new saved-role guard; 2.83 has the known manual-entry regression. No automatic rollback or database restore is performed.
