Sponsor Intel — Advert Check 0.1.1 (developer preview)

Install on desktop Chrome or Edge:
1. Extract the ZIP into a folder you will keep.
2. Open chrome://extensions or edge://extensions.
3. Enable Developer mode, choose Load unpacked, select the extracted folder
   containing manifest.json, then pin Sponsor Intel from the extensions menu.
4. Open one job advert, expand its full description, click Sponsor Intel,
   and choose Read this advert. Review the extracted text before checking.

You can select the advert first or paste it when automatic reading cannot
isolate the role. Only English-language UK advert wording is supported.
Unknown wording is not a refusal. A licence is not a job sponsorship offer.
No promise of compatibility with every website or accurate legal assessment.

This is a local developer preview, not a Chrome/Edge store-approved release.
Managed browsers may block installation; do not bypass their policies.
No automatic updates: download a new version only from Sponsor Intel,
replace the files and use Reload on the extension page. Remove the extension
through that same page. Do not disable browser security to install it.

Privacy: activeTab and scripting give temporary access after your click.
There are no host permissions, background tasks, network requests, analytics,
storage, cookies, clipboard permission, model calls or account integration.
Form controls and editable regions are excluded from automatic capture.
The popup holds text only until it closes. Do not paste private application
answers or CVs. Opening a help link is ordinary website navigation.
