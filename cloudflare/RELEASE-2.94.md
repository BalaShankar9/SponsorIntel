# 2.94 — Review exact application content

Adds per-role document/answer/destination previews, private immutable content approvals, exact-text downloads, revocation/history and interrupted-request reconciliation. The server pins the actual saved role CV/letter and current applicant-confirmed answers; the master CV cannot silently fill a missing role document. Unicode and line endings are retained in raw UTF-8 fingerprints. Facts, job evidence, destination, document or parent-state changes invalidate use. Late edits, account deletion, fact revocation, pause and original-close/change races are guarded at insertion.

**Scope:** content review only, no employer transmission, permitted-provider adapter, dispatch approval, automatic submission, AI call or guaranteed document quality. PDF/Word attachments and employer-specific questions need their own exact review. Existing 100-role selections remain; approval is per role within the unchanged 60/hour API cap.
