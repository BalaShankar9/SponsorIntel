The provider trace proves the timeout; it does not establish that prompt size was its cause.

For future runs, policy `sourced-guides-eligible-planner-v6` gives the planner each eligible candidate's full approved facts once. It retains every condition, required segment, source identity/hash, date, expiry, proposed slot and limitation. Non-selectable sources retain only ID/title/kind and an explicit non-selection limitation. Queue records, aggregate metrics, complete-day and browser measurement boundaries, missing values, platform observations and all measurement caveats remain unchanged. Raw original source evidence stays in the retained context and still reaches the different-model critic. Candidate and publication validation is unchanged.

Each new context records `eligible-facts-v1`, the exact projected input SHA-256 and character counts. Before any model reservation, the planner reconstructs and verifies that input. The policy selects the input contract; older runs keep the old projection and prompt without having their contexts rewritten. A new version does not create another daily attempt or clear an owner hold. Input mismatch stops before a call. Capturing a contract, making no-post decisions and inspecting history require no model call.
