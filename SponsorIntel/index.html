⚙️ API Key Configuration

Configure your free API keys to unlock live data scraping. All keys are stored locally on your machine only.

Free at developer.company-information.service.gov.uk — get company details, directors, financials, SIC codes
Free at reed.co.uk/developers — scrape live UK job listings with salary data
Free at developer.adzuna.com — scrape jobs + salary intelligence data

🆓 How to Get API Keys (All Free)

1. Companies House API — Go to developer.company-information.service.gov.uk, sign up, create an app, copy the API key. Gives you: company registration details, directors, SIC codes, financial filing status.

2. Reed API — Go to reed.co.uk/developers, register for free, and get your API key instantly. Gives you: live UK job listings with salary, location, description.

3. Adzuna API — Go to developer.adzuna.com, sign up, create an app. You'll get an App ID + App Key. Gives you: aggregated job listings from 1000+ sources + salary predictor.
