## Sponsor Intel Job notes: privacy and your information

This policy describes Sponsor Intel Job notes 0.2.0, a companion for reading public job adverts. Its wording checks run on your device without an account or a model service.

### Enabling a tab

When you choose **Turn on for this tab**, the extension checks the current tab's address and adds its packaged companion to that ordinary HTTP or HTTPS page. While enabled, it observes changes in the page and examines rendered job links, titles and nearby card structure to place Sponsorship notes controls. This continues while you browse or scroll that page. It does not automatically open jobs, fetch hidden descriptions or examine other tabs.

This bounded observation happens within the enabled page, unlike the older Advert Check popup's single capture. Reloading or moving to a new document requires enabling again. Changes inside an already enabled page may continue to be observed until you turn it off.

### Reading and checking an advert

When you choose **Read full description**, the companion tries to match the visible description to the selected job using its address, links or page identifiers. If it cannot match a selected card, it asks you to open the complete role or paste its public text. A page-level read can fall back to the main page text and asks you to review its scope.

The panel holds captured or pasted text, job title and original link, website hostname and a local reading time. You can edit these details. Automatic capture excludes form controls, editable regions and detected hidden content; closed advert sections must be expanded. These checks cannot guarantee that arbitrary page text or pasted text contains no personal information. Use public adverts only; do not paste CVs, passwords, private messages or application answers.

After you confirm one complete advert, local phrase rules produce a wording result and quotations. Changed text or job identity invalidates the previous result. These checks are not employer confirmation, current sponsor-licence verification, vacancy verification, personal eligibility advice or application submission.

### Temporary state and controls

The enabled companion keeps working text and results in page memory. It does not automatically upload them or write them to browser storage, files, a cloud account or database. **Clear** removes the working text and result. Closing the notes clears their advert text; **Off** removes the panel, markers and observer. This describes extension behavior, not secure erasure from browser or operating-system memory. You can also remove the extension in browser settings.

There is no extension analytics or advertising tracker. The companion sends no advert text or result to Sponsor Intel or a model service. The website being read still has its own scripts and privacy practices; the companion does not make that website private.

### Files you choose to download

**Download job notes** creates a JSON file only when you choose that action after confirming the complete advert. It contains the reviewed full advert, public source link, title, employer/location you supplied, observation time, text checksum and local wording quotations/result. It contains no automatically gathered applicant profile or CV. It can contain anything you pasted into the advert or metadata fields, so review those fields before downloading.

Your browser controls where the file is saved. It remains on your device until you manage it. Closing, clearing or disabling the companion does not delete downloaded files. A checksum detects a changed body; it is not proof that an employer issued the advert or its claims are correct.

Workspace import is prepared separately and is not in the currently live website release. Once available, choosing a file on Sponsor Intel and confirming **Add role** will use the website's workspace and account handling. The extension itself does not sign you in, send the file to your profile, generate documents, contact employers or submit applications. Website saving, document preparation and any model use have their own controls and disclosures. Downloading is not proof of an account save.

### Permissions and external links

The extension requests **activeTab** and **scripting** for temporary, user-invoked access and packaged code execution. It does not request persistent access to all websites, browser history, clipboard reading, storage or extra account permissions. It bundles executable code and does not download remote code.

Opening an original job link visits that website. The Sponsor Intel help link visits the separate website without attaching advert text or results. Those visits have ordinary website request handling. Read Sponsor Intel's **Privacy & use** information at [About](https://sponsorintel.london/about). Your browser and the job website have their own privacy practices.

### Limited Use

Sponsor Intel Job notes uses information obtained through browser APIs in accordance with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/limited-use), including its Limited Use restrictions. It uses that information only for the local job-card, advert-reading and user-chosen export features described here.

### Questions and changes

For a privacy question or problem, open [Sponsor Intel](https://sponsorintel.london/about) and choose **Feedback**. That is a separate website submission; include only information you want the support team to review, without passwords or private application documents. This policy does not promise a response time.

Changes to reading, storage or sharing require updated disclosures. Check the extension version and policy before enabling new behavior.
