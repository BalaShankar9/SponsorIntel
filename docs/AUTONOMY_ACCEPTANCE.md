## Definition of a completed autonomous cycle

A run must retain its real trigger, input/source versions, responsible components, decisions, consumed budget, output, external result where applicable, errors and recovery. At least one complete scheduled cycle must be observed without an owner manually supplying intermediate results. A successful test or an owner-triggered run remains labelled as such.

Learning means measured revisions to versioned policies and prompts after comparison against a held-out baseline. Models cannot change their own permissions, spending caps, accepted source list or live code. Engineering changes continue through tests, deployment checks and an auditable release.
